# inCruises · BoardTeam — сайт

Промо-сайт независимого партнёра inCruises, собранный по утверждённой презентации.

**Технологии:** [Astro](https://astro.build) (статический сайт), Tailwind CSS 4, GSAP (ScrollTrigger, MotionPath, DrawSVG) — анимации, Lenis — плавная прокрутка, NumberFlow — «прокручивающиеся» цифры.
Хостинг — бесплатный, GitHub Pages: сайт публикуется автоматически при каждом изменении в ветке `main`.

---

## Что где менять

| Что | Файл |
| --- | --- |
| Контакты (WhatsApp, Telegram, Instagram), реферальная ссылка | `src/config.ts` |
| Все тексты, цифры, бонусы, планы Classic/Premium, таблица лидерского бонуса | `src/data/content.ts` |
| Фото и видео историй | `src/assets/stories/`, `src/assets/video/` и `src/components/Stories.astro` |
| Картинка для превью ссылки в мессенджерах | `public/og.jpg` (1200×630) |

Контакты, которые оставлены пустыми, на сайте не показываются. Кнопка «Вступить в клуб» ведёт в WhatsApp, если номер указан.

## Запуск на своём компьютере

Нужен Node.js 22.23 или новее.

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:4321

```bash
npm run build      # собрать готовый сайт в папку dist/
npm run preview    # посмотреть собранную версию
```

## Публикация на GitHub Pages (один раз)

1. Создайте репозиторий на GitHub и загрузите в него этот проект (ветка `main`).
2. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Дальше любое изменение, загруженное в `main`, публикуется само (вкладка **Actions** показывает ход публикации).

**Свой домен** (например, `incruises-team.kz`): Settings → Pages → Custom domain, затем у регистратора домена добавьте CNAME-запись на `<ваш-логин>.github.io`.

## Структура

```
src/
  components/      секции страницы (Hero, Stats, Plans …) и графика (art/)
  data/content.ts  все тексты и цифры
  config.ts        контакты и меню
  scripts/motion.ts  общие анимации: плавный скролл, счётчики, появление блоков
  styles/global.css  дизайн-система: цвета, шрифты, кнопки
public/            иконка сайта, превью для соцсетей
.github/workflows/deploy.yml  автопубликация на GitHub Pages
```

Анимации отключаются автоматически, если в системе пользователя включено «Уменьшить движение».
